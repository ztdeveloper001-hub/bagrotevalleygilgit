# Public Assets
Upload your real images of Bagrote Valley here. I have already updated the website to look for these specific filenames:

1. **hero-bagrote.jpg** -> Main image on the Home page.
2. **explore-bagrote.jpg** -> Main image on the Explore page.

### How to upload:
1. Use the file explorer on the left.
2. Right-click the `public` folder.
3. Select "Upload Files".
4. Rename your images to match the names above.

Once uploaded, the website will automatically show your real photos!
